# Continuous character rig study

Open [Clockwork Hello — continuous rig study](clockwork-continuous.otoon) with
**Scene → Open** in the current source build of the desktop app. The 48-frame scene contains 15 original
artwork Parts. Each arm and leg is one deforming image with a middle elbow or
knee joint. Four saved bone-tip links keep the hands and feet attached without
separate position keys.

Scrub frames 0–24 to see the four limb bends. At frame 30, the left sleeve
switches to a separately bound substitution, the left hand changes to a fist,
and the face switches to a three-quarter view with an Ah mouth. At frame 40,
the saved Front view returns those drawings to their original choices. The
project is editable; use **Rig → Follow parent bone tip** on a selected hand or
foot to inspect or toggle its link. The saved example is checked against the
same scene built and rendered by the native regression test.

The art is original GPL-3.0-or-later work generated by the repository's
`scripts/generate_harmony_fixture.py` and
`scripts/generate_harmony_continuous_limbs.py`. The owner's Toon Boom images
were visual references; no third-party pixels are included. This is an HM-06
rig study and does not establish final character-art acceptance.
