# P09 — Core deformation

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Animate curved limbs and flexible drawings with stable rest poses and attachments.

**Status:** planned. **Dependencies:** P08. **Effort:** 20–36 focused engineer-weeks.

**Milestone:** v0.6 — deformable characters.

## Work packages

### P09-W1

Implement bone, curve and envelope evaluation over an explicit rest-space mesh with consistent texture coordinates.

### P09-W2

Add influence editing, multiple poses, generated envelopes and deformation quality/visibility controls.

### P09-W3

Implement kinematic attachments and bake-to-drawings with provenance and bounded approximation error.

## Exit criteria

- Complete WF-05 and compare rest, posed and baked drawings within declared tolerances.
- Test joints, folds and extreme poses on B4 with a checker texture; reject invalid weights predictably.
- Animation remains reproducible after reopen and template reuse.
- Profile interactive edits separately from final render; expose quality settings without changing saved intent.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Deformation evaluation contract
- Rig fixtures and bake accuracy report
- Artist-facing core deformation manual
