# P14 — Morphing and drawing interpolation

[Roadmap](../README.md) · [All phases](../PHASES.md)

Interpolate compatible drawings with artist-controlled correspondences.

**Status:** planned. **Dependencies:** P04, P06. **Effort:** 18–34 focused engineer-weeks.

**Milestone:** Morphing release.

## Work packages

### P14-W1

Define compatibility rules for contour topology, art layers, palette references and holes.

### P14-W2

Implement correspondence hints, intermediate keys, timing and preview; preserve source drawings and derived results separately.

### P14-W3

Add explicit diagnostics and bake options for unsupported topology changes and raster content.

## Exit criteria

- Complete shape interpolation fixtures with holes and alpha without losing contour identity.
- An incompatible pair reports actionable reasons instead of silently producing a broken drawing.
- Hint editing is reversible and deterministic across save/reopen.
- Compare endpoints exactly and intermediates against approved animation references with bounded geometric error.
