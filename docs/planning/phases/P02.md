# P02 — First complete frame-by-frame film

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

An animator can draw a two-second bouncing ball, save it, reopen it and export 48 PNG frames.

**Status:** planned. **Dependencies:** P01. **Effort:** 16–28 focused engineer-weeks.

**Milestone:** v0.1 — usable vertical slice.

## Work packages

### P02-W1

Implement pencil strokes, pressure width, erasing, selection and stable palette references on vector drawings.

### P02-W2

Connect drawing exposures, simple layers, onion skin and playback to the shared time model; use a minimal ordered compositor with alpha-over.

### P02-W3

Add still-image import and cancellable PNG sequence export using the same scene evaluator as preview.

## Exit criteria

- Complete WF-01 at 1080p/24fps without editing files outside the app; exactly 48 correctly numbered frames export.
- Undo a complete stroke, exposure edit and layer reorder; save/reopen retains semantic equality.
- Measure B0 tablet latency, pressure fidelity and display scaling on the declared device matrix.
- Rerender the reopened scene and compare pixels within the documented backend tolerance; preview and export agree on framing.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- v0.1 experimental desktop package
- Redistributable bouncing-ball fixture
- First user manual and recorded workflow
