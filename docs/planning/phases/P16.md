# P16 — Production interchange

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Exchange layered artwork, editorial timing and compositing results with external tools.

**Status:** planned. **Dependencies:** P12, P15. **Effort:** 16–30 focused engineer-weeks.

**Milestone:** Pipeline interoperability.

## Work packages

### P16-W1

Add layered PSD import/export with explicit layer/mask/blend subsets; evaluate PSD-specific tooling where generic image IO cannot preserve layers.

### P16-W2

Implement vector interchange, linked image updates, scan/vectorization workflow and OTIO timeline mapping.

### P16-W3

Add editorial and After Effects-oriented interchange adapters with exact supported schemas, conversion reports and portable references.

## Exit criteria

- Round-trip redistributable layered/vector fixtures and list every unsupported construct; no blanket lossless claim.
- Changing a linked image creates a controlled revision and can be undone or reverted.
- Import editorial timing at rational rates without silently shifting audio or exposures.
- Render comparison fixtures for downstream exchange and document version-specific limitations.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Interchange matrix and fixture corpus
- Conversion reports and relinking tools
- External workflow guides
