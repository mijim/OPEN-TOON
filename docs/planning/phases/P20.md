# P20 — Optional local AI tools

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Offer opt-in assistive image operations with explicit model provenance and reversible results.

**Status:** planned. **Dependencies:** P12, P15. **Effort:** 18–40 focused engineer-weeks.

**Milestone:** Optional AI extension.

## Work packages

### P20-W1

Evaluate ONNX Runtime and redistribution-compatible models for masks, erase, outpaint, upscale and fill separately.

### P20-W2

Implement cancellable worker jobs, model/download manifests, resource budgets and preview/apply through document transactions.

### P20-W3

Provide offline operation after optional model installation, clear generated-content provenance and quality comparisons with manual workflows.

## Exit criteria

- The editor installs, opens, draws and exports without any model, login or network service.
- Every enabled operation has a usable licensed model, evaluated visual quality and explicit memory/hardware requirements.
- Cancel or reject a generated result without changing source artwork; applying it is undoable.
- No user artwork is uploaded by default; any later remote adapter requires a separately explicit action and disclosure.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Optional AI worker and model registry
- Per-operation quality/resource reports
- Model licenses and generated-result metadata
