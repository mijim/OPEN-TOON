# P01 — Application foundation and English design system

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Open a real local document in a minimal English desktop shell with reversible edits and safe recovery.

**Status:** planned. **Dependencies:** P00. **Effort:** 12–22 focused engineer-weeks.

**Milestone:** Foundation.

## Work packages

### P01-W1

Create CMake/Ninja targets, Conan lockfiles, module boundaries, CI builds and sanitizer profiles; build an English contributor guide.

### P01-W2

Implement stable IDs, rational time, command transactions, immutable render snapshots, SQLite/blob storage, migrations and recovery.

### P01-W3

Create monochrome QML tokens, keyboard commands, focus rules, dock layout persistence and accessible English strings; audit the English glossary against command IDs, built-in assets and documentation.

## Exit criteria

- Create/save/reopen a scene and undo/redo document configuration changes through the real command API.
- Simulate disk-full and termination; recover the last committed revision with actionable English errors.
- Build on Windows/macOS/Linux; run physical tablet smoke checks on available reference hardware and explicitly mark untested device profiles.
- Inventory all visible strings, accessibility labels and first-party docs; English is the release language and non-Latin user text round-trips.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Modular desktop shell and headless test target
- Versioned project format draft and recovery protocol
- English glossary, UI tokens and dependency notices
