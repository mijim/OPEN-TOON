## Exit criteria

- Record hardware, dependency revisions, build flags, licenses and raw measurements.
- Select one primary renderer and one fallback; prove a pressure-sensitive stroke on each target OS.
- Interrupt every save boundary without publishing missing blobs; demonstrate a viable fill and curve deformation.
- Accept or reject each spike with an ADR; an unresolved core blocker prevents P01 production contracts.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.
