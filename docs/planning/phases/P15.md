# P15 — Advanced effects, particles and OpenFX

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Create procedural effects and particle scenes inside the managed compositor.

**Status:** planned. **Dependencies:** P12, P13. **Effort:** 24–44 focused engineer-weeks.

**Milestone:** Advanced compositing release.

## Work packages

### P15-W1

Add remaining filters, channel operations, generated mattes, texture animation, distortions and surface/normal lighting.

### P15-W2

Build a seeded particle simulation with emitters, forces, collisions, lifecycle, caches and versioned baked results.

### P15-W3

Evaluate OpenFX host support in an isolated worker with explicit supported suites, capabilities and plugin license records.

## Exit criteria

- Rerender seeded particles identically on the supported deterministic path; timeline jumps use valid simulation state.
- Test out-of-frame regions, premultiplied alpha, HDR values and tiled boundaries for every added effect.
- A crashing or incompatible external plugin reports failure without damaging the project.
- Benchmark B3/B5 memory and cancellation, and publish operator-specific tolerances and OpenFX compatibility.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Advanced operator catalog
- Particle cache format and examples
- OpenFX support matrix

## Quality and risks

**Fixtures:** B3, B5, B6. Use only the supported subset at this phase and record its parameters.

**Quality requirements:** NFR-009, NFR-010, NFR-011, NFR-012, NFR-018, NFR-019, NFR-025, NFR-027; see [the quality catalog](../../catalog/nonfunctional.json).

Simulation determinism, expensive effect chains and third-party plugin behavior.
