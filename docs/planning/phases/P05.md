# P05 — Raster and textured brush engine

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Mix tiled bitmap artwork and vector drawings with responsive textured brushes.

**Status:** in_progress. **Dependencies:** P04. **Effort:** 14–26 focused engineer-weeks.

**Milestone:** Mixed-media drawing.

## Work packages

### P05-W1

Integrate libmypaint through a brush/tile adapter; benchmark color conversion, stroke sampling and undo tile diffs.

### P05-W2

Implement bitmap layers, selection, resolution changes, texture-backed vector brushes/pencils and deterministic preset serialization.

### P05-W3

Evaluate an ABR subset importer with explicit compatibility reporting; preserve original presets and reject unsupported variants safely.

## Exit criteria

- Paint B3 at 4K with bounded tiles/caches and cancellable operations; report cold/warm memory separately.
- Compare undo/reopen stroke output and pressure transitions using recorded input streams.
- Import documented ABR fixtures or publish precise unsupported fields; do not claim general Photoshop brush compatibility.
- Mix raster and vectors while keeping premultiplication and color transforms consistent.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Brush adapter and preset schema
- Raster workflow sample
- ABR support matrix and memory benchmark
