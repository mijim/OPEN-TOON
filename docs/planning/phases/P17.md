# P17 — Mixed 2D and 3D scenes

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Integrate imported 3D assets into a controlled 2D animation workflow.

**Status:** planned. **Dependencies:** P06, P10, P16. **Effort:** 24–48 focused engineer-weeks.

**Milestone:** Mixed-media 3D release.

## Work packages

### P17-W1

Evaluate ufbx/fastgltf import adapters, coordinate/unit conversions, materials, hierarchy, skinning and animation clips.

### P17-W2

Add 3D subnode visibility/overrides, normalized depth and compositing with 2D planes through a declared renderer contract.

### P17-W3

Add an optional external-render bridge with versioned job manifests and portable asset references.

## Exit criteria

- Complete WF-09 using redistributable models with known units, skin weights and animated clips.
- Compare axis/handedness and camera projections with reference transforms; texture paths remain portable.
- Document which material/shader features are mapped, approximated or unsupported.
- GPU failure or external renderer failure yields recoverable job errors and preserves editable 2D work.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.
