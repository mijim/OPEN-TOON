# P18 — Game animation export

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Deliver predictable sprite and skeletal assets to a documented open runtime.

**Status:** planned. **Dependencies:** P13, P15, P16. **Effort:** 16–30 focused engineer-weeks.

**Milestone:** Game delivery release.

## Work packages

### P18-W1

Implement atlas packing, variants, anchors/collision metadata and effects baking with deterministic frame bounds.

### P18-W2

Add game-oriented bones and an independently documented animation runtime format; avoid dependence on proprietary SDKs.

### P18-W3

Build a minimal open reference runtime and import example; define runtime skinning, color and interpolation support.

## Exit criteria

- Complete WF-10 and compare runtime playback with baked reference frames.
- Verify atlas padding, rotated regions, trim offsets and transparent borders at multiple scales.
- Report unsupported rig/effect behavior and offer a bake fallback with size estimates.
- Version the exported schema and test a previous exporter version against the runtime.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Open runtime schema and example player
- Game export fixtures
- Bake/support report
