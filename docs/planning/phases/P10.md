# P10 — Node compositor and managed color

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Compose scenes with editable node graphs, masks, effects and consistent color-managed output.

**Status:** planned. **Dependencies:** P06, P07, P09. **Effort:** 20–38 focused engineer-weeks.

**Milestone:** v0.8 — compositing.

## Work packages

### P10-W1

Promote the early ordered compositor to a typed acyclic graph with groups, switches, viewer/output nodes and dirty propagation; migrate old projects.

### P10-W2

Build the node editor as a view over the document graph; implement basic blending, opacity, blur, glow, shadows, color correction and mattes.

### P10-W3

Integrate OpenColorIO and HDR-capable image IO, define working/display/output transforms and add multi-output/headless rendering.

## Exit criteria

- Complete the supported 2D subset of WF-08 with masks, camera movement and multiple outputs.
- Validate cycles, incompatible ports and missing assets before render with English node-specific diagnostics.
- Use B5 charts to verify alpha, linear-light composition and display/export transforms.
- Change one upstream parameter and show correct selective invalidation; render the same revision through UI and CLI.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Typed compositor and node operator contract
- Color pipeline specification
- 2D compositing fixture and output comparisons

## Quality and risks

**Fixtures:** B1, B3, B5. Use only the supported subset at this phase and record its parameters.

**Quality requirements:** NFR-009, NFR-010, NFR-011, NFR-012, NFR-018, NFR-025, NFR-027; see [the quality catalog](../../catalog/nonfunctional.json).

Graph migration, color-space errors and GPU/CPU consistency.
