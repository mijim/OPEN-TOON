# P03 — Timeline, Xsheet and paperless workflow

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Animate longer scenes using consistent timeline and Xsheet exposure editing.

**Status:** planned. **Dependencies:** P02. **Effort:** 12–20 focused engineer-weeks.

**Milestone:** v0.2 — paperless animation.

## Work packages

### P03-W1

Implement interval-based holds, insert/delete, cycles, timing on twos/threes, stretch and multi-range copy; virtualize timeline and Xsheet views.

### P03-W2

Add advanced onion skin, shift-and-trace, flip/desk views, thumbnails, drawing marks and registration tools.

### P03-W3

Extend workspace, shortcut, layer grouping, clone/sync, annotations and element management without duplicating document state.

## Exit criteria

- Perform equivalent edits in timeline and Xsheet and obtain identical exposure intervals after undo/reopen.
- Edit a sparse 10,000-frame scene without allocating a UI item for every cell.
- Complete WF-02 rough-to-cleanup using the supported vector subset; preserve registration.
- Test keyboard-only editing, focused shortcuts and multi-selection across collapsed groups.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Shared exposure editor with two synchronized views
- Paperless workflow guide
- Large-timeline performance report

## Quality and risks

**Fixtures:** B1, B2. Use only the supported subset at this phase and record its parameters.

**Quality requirements:** NFR-003, NFR-006, NFR-008, NFR-014, NFR-027; see [the quality catalog](../../catalog/nonfunctional.json).

Interval boundary errors; accidental drawing sharing versus duplication.
