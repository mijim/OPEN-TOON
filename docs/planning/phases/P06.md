# P06 — Keyframe animation and multiplane cameras

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Animate transform hierarchies and camera moves with predictable timing and curves.

**Status:** in_progress. **Dependencies:** P01. **Effort:** 16–28 focused engineer-weeks.

**Milestone:** Keyframe animation.

## Work packages

### P06-W1

Implement setup/animate modes, pegs, pivots, transform channels, stepped/continuous keys, autokey and batched key editing.

### P06-W2

Build curve/ease and motion-path editors with explicit interpolation, velocity and extrapolation semantics.

### P06-W3

Add multiple cameras, animated orthographic framing, multiplane Z, staging views and reusable motion transfers; 3D views here show 2D planes, not imported meshes.

## Delivery priority

Use contract-level prerequisites for early delivery. Full phase exit criteria and catalog acceptance remain unchanged unless explicitly revised below.

- [HM-13 — Output camera and framing](../HARMONY-MOMENT.md#hm-13): Add an explicit active orthographic output camera with animated pan/zoom/rotation and nonrendering framing guides. Separate camera edits from canvas navigation; retain drawing-local coordinates.

## Exit criteria

- Animate a camera move and character hierarchy; reopening preserves all evaluated keyframe values.
- Verify parent-child transforms and pivot edits with nonuniform scale and negative scale.
- Scrub and export identical camera framing at integer and rational frame rates.
- Copy and retime key ranges without changing unrelated channels; undo restores the complete edit.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

- Curve editor and camera documentation
