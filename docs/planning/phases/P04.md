# P04 — Professional vector drawing and palette workflow

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Clean up and recolor production drawings using editable vector geometry and linked palettes.

**Status:** in_progress. **Dependencies:** P02. **Effort:** 20–36 focused engineer-weeks.

**Milestone:** Vector production toolkit.

## Work packages

### P04-W1

Add region-aware fills, gap closing, invisible strokes, contour/centerline editing, width profiles, cutter, smoothing and curve primitives.

### P04-W2

Implement vector brushes, gradient/texture fills, drawing deformation tools, guides, stamps and outline-safe text; retain editable text metadata where supported.

### P04-W3

Add four art layers, color models, palette variants, palette repair and multi-drawing operations; explicitly define drawing sharing semantics.

## Delivery priority

Use contract-level prerequisites for early delivery. Full phase exit criteria and catalog acceptance remain unchanged unless explicitly revised below.

No critical-path slice is owned here; retained work follows the Harmony Moment unless a measured blocker requires it.

## Exit criteria

- Complete WF-02 and WF-03 with recoloring propagated by stable swatch IDs.
- Exercise self-intersections, near-coincident curves and small gaps; undo never drops unrelated contours.
- Transform or cut a selection without silently converting all vectors to raster.
- Preserve all art-layer and palette relations across save, clone and import/export; record tolerances for curve flattening.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Vector editing and fill topology specification
- Day/night palette fixture
- Golden drawings for pathological geometry
