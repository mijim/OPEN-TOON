# P12 — Automation and extension foundations

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Automate editing and rendering through a documented, versioned command API.

**Status:** planned. **Dependencies:** P11. **Effort:** 12–24 focused engineer-weeks.

**Milestone:** Automation release.

## Work packages

### P12-W1

Expose stable document queries and transactions through a C++ application API and pybind11 Python bindings.

### P12-W2

Build script editor, custom actions, explicit trusted-script permissions and a separate process for restricted automation; Python bindings themselves are not a sandbox.

### P12-W3

Add CLI batch jobs, deterministic expression evaluation, cancellation, version negotiation and plugin manifests.

## Exit criteria

- A script generates and renders a scene using the same validated commands and undo rules as the UI.
- Reject unsupported API versions with a migration hint; never execute scripts embedded in a project automatically.
- A terminated worker leaves no partial document transaction or completed-looking output.
- Document which scripts are trusted and which restrictions are enforced by OS process boundaries, not a misleading restricted Python namespace.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Versioned automation SDK
- Script examples and extension policy
- CLI job protocol
