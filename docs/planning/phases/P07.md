# P07 — Sound and practical media output

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Edit dialogue against drawings and deliver synchronized image or movie output.

**Status:** planned. **Dependencies:** P01. **Effort:** 14–26 focused engineer-weeks.

**Milestone:** v0.3 — drawing with sound.

## Work packages

### P07-W1

Use miniaudio for device playback/mixing and a restricted FFmpeg adapter for decoding/encoding; keep one authoritative rational timeline clock.

### P07-W2

Add waveforms, trim/offset, gain, scrub, audio library, preview quality and render-range controls.

### P07-W3

Add video import, video/audio export, GIF and standalone playback; distinguish input decoding support from redistributable output codec profiles. Deliver manual viseme mapping/correction after character substitution contracts; evaluate automatic detection separately after manual editing works.

## Delivery priority

Use contract-level prerequisites for early delivery. Full phase exit criteria and catalog acceptance remain unchanged unless explicitly revised below.

- [HM-10 — Audio clock, waveform and manual timing](../HARMONY-MOMENT.md#hm-10): Adopt one playback backend after the miniaudio spike; start with WAV/PCM, waveform pyramids, trim/offset/gain, limited mixing and frame scrub. Audio device time drives playback, while headless sampling uses the same rational scene mapping.
- [HM-11 — Mouth mapping and editable lip sync](../HARMONY-MOMENT.md#hm-11): Map a small labelled viseme set to each character and edit held mouth timings against audio. Import a documented timing JSON with rational conversion and previewed merge ranges; preserve manual corrections.
- [HM-14 — Synchronized preview and deterministic delivery](../HARMONY-MOMENT.md#hm-14): Preview the bounded shot from revision-keyed caches with visible dropped-frame/quality state. Export an exact-range PNG sequence plus synchronized PCM WAV and an explicit timing/color manifest; save/reopen the same immutable revision before comparing output.

## Exit criteria

- Play and export a ten-minute rational-rate scene with audiovisual drift within NFR-007.
- Cancel render and device changes cleanly; no partial output is reported as complete.
- Check waveform, trim and gain against a known waveform and exact sample boundaries.
- Install the minimal licensed media build on clean target systems and list available codecs at runtime.
- Complete WF-07 after the character substitution subset, preserving manual corrections and flagging unmapped labels; English and Spanish detector evaluations remain distinct.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.
