# P08 — Cut-out rigs, reusable assets and lip sync

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Build a reusable character, animate its rigid parts and map dialogue to mouth drawings.

**Status:** in_progress. **Dependencies:** P06, P07. **Effort:** 16–30 focused engineer-weeks.

**Milestone:** v0.5 — cut-out animation.

## Work packages

### P08-W1

Implement breakdown, hierarchy editing, pivots, Z ordering, substitutions, pose copying and patching seams.

### P08-W2

Create versioned local libraries, templates, symbols, previews and paste modes; instantiate assets without accidental shared edits.

### P08-W3

Add manual lip-sync editing and mouth mapping; evaluate Rhubarb as an optional subprocess, retaining editable generated timing.

## Exit criteria

- Complete WF-04 with a reusable waving character and independently editable instances.
- Complete WF-07 using both manual keys and imported mouth timings; Spanish and English recordings are separate evaluation fixtures.
- Reimport a rig template without ID collisions or lost palette dependencies.
- Document detector limitations: Rhubarb speech mode is English-oriented; language-independent mode needs its own quality results.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.

## Deliverables

- Cut-out rig and asset schemas
- Character and dialogue examples
- Optional lip-sync adapter report
