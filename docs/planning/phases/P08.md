# P08 — Character assets, substitutions and accessible rig controls

[Roadmap](../README.md) · [All phases](../PHASES.md)

> Generated from `roadmap.json`; edit the canonical JSON and regenerate.

Build reusable characters with first-class parts, substitutions, poses and declarative controls; guide initial setup through an editable Quick Rig recipe.

**Status:** in_progress. **Dependencies:** P02. **Effort:** 23–42 focused engineer-weeks.

**Milestone:** Reusable character authoring; Harmony Moment core subsets first.

## Work packages

### P08-W1

Implement breakdown, hierarchy editing, pivots, Z ordering, substitutions, pose copying and patching seams.

### P08-W2

Create versioned local libraries, templates, symbols, previews and paste modes; instantiate assets without accidental shared edits.

### P08-W3

Implement saved partial poses, canvas widgets, one-dimensional pose sliders, mapping and compact character dashboards with stable portable bindings; no scripting prerequisite.

### P08-W4

Deliver guided Quick Rig: map named parts, place joint guides, preview/correct FK hierarchy and controls, then commit once; extend recipes to proven deformer/IK capabilities only after their gates.

## Delivery priority

Use contract-level prerequisites for early delivery. Full phase exit criteria and catalog acceptance remain unchanged unless explicitly revised below.

- [HM-03 — Character identity, pegs and substitution sets](../HARMONY-MOMENT.md#hm-03): Create a character root and stable part roles; keep separate transform hierarchy and render order. Add preserve-world reparenting, rest pivots, named thumbnail substitutions, held selector tracks and coordinated variant sets.
- [HM-07 — First-class poses and declarative animator controls](../HARMONY-MOMENT.md#hm-07): Save named masked poses including discrete substitutions; apply/mirror only explicitly mapped parts. Add direct widgets, limited sliders/switches and a compact character dashboard. Pose interpolation blends compatible numeric properties; discrete variants use an explicit threshold rule. Animator and Rig workspaces expose the same document at different detail levels.
- [HM-08 — Quick Rig guided FK recipe](../HARMONY-MOMENT.md#hm-08): Assign part roles and place joint guides directly on canvas; preview an editable FK hierarchy and control set before one commit. Offer a simple biped recipe and manual correction. Generated rigs use the same model as hand-authored rigs.

## Exit criteria

- Complete WF-04 with a reusable waving character and independently editable instances.
- Reimport a rig template without ID collisions or lost palette dependencies.
- Capture/apply a masked pose and switch coordinated substitutions without changing unrelated animation.
- Create/cancel/undo Quick Rig, then edit the same document in the full rig workspace; two template instances have independent bindings.
- Declarative controls remain usable without Python; advanced scripted controls belong to P12.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.
