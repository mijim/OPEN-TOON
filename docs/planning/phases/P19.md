## Exit criteria

- Complete WF-11 under concurrent edits, network loss and expired leases; no silent last-writer data loss.
- A requeued render job cannot publish conflicting outputs for one revision.
- Audit access and lock state using English diagnostics; offline checkout remains usable under documented rules.
- Test backup/restore, migrations and worker version skew in a small real production pilot.

Apply the [shared Definition of Done](../EXECUTION.md) as well; a visual control alone never completes a feature.
