# ADR-020 — Additive whole-vector selection

Accepted for experimental.9, 2026-09-21. Extends ADR-014/015 for the partial
VEC-009 capability in the P04 drawing workflow. Domain owner:
`modules/document/drawing_selection`; presentation owner:
`adapters/qt/canvas_vector_selection`. No dependency or format change.

## Interaction and ownership

Select (V) picks a whole vector with the existing screen-space hit tolerance.
Shift-click adds; Alt-click subtracts (Alt wins if both are held). Repeated additions
are idempotent. Modified clicks take priority over bounding-box handles; to constrain
a transform, start dragging its handle and then hold Shift. An ordinary click on an
unselected stroke inside the group box selects that stroke. Empty space inside the
box still moves the group. Existing topmost art-layer picking order is preserved.

Marquee (M), with the Vectors filter, adds enclosed strokes with Shift and subtracts
with Alt. The operation is captured on press; membership changes only on release.
Escape or a lost grab cancels a modified marquee without changing the old selection.
A vector must fit entirely including half its nominal width. Raster masks, lasso,
partial contours and cross-layer selection are not included in this subset.
Raster/mixed selections reject modified selection gestures with a visible message.

A vector selection stores explicit stable stroke IDs, deduplicated in drawing order.
Its tight integer bounds include nominal widths; the rectangle does not define group
membership. Individual dotted bounds show selected objects inside the group box.
Properties reports the actual count, or full object properties when one vector remains.
Selection is unsaved view state. Switching between Select and Marquee retains vector
membership and uses the Vectors filter. Changing frame, layer, document or another
tool clears it. Changing the media filter explicitly clears the old selection.

## Editing and publication

Move/scale/rotation previews and region operations use the frozen ID set and vector-only
media regardless of the last raster filter. Unselected artwork inside the box must
stay unchanged. The domain returns the resulting IDs for discrete region edits;
duplicating selects only the newly allocated copies, even at zero offset or over an
original. It never reselects by containment. Output IDs publish only after a successful
transaction, alongside the document. Undo/redo restores artwork; selections are cleared
by history navigation, as before.

Qt remains the input/painting adapter; bounds and edit identity results remain Qt-free.
No new geometry engine is needed for this whole-stroke subset. The existing Session,
renderer, storage and transform paths provide one command per edit and shared export.
Large-scene performance and artist acceptance remain unqualified.

## Acceptance evidence

- Domain fixture: separated selected primitives with an unselected stroke and raster
  inside their box; zero-offset duplicate IDs, subsequent move/delete, metadata,
  exact original preservation and atomic rejection without publishing output IDs.
- Native macOS fixture: Shift/Alt picking and marquee, idempotence, Properties count,
  tool switching, a bystander inside the box, mirrored/rotated view movement,
  group scaling, cancellation, overlapping duplicate/move/delete and exact undo.
- Save/reopen checks compare both document semantics and rendered pixels.

Fixture artwork is original synthetic geometry generated by the tests. Physical pen,
Windows/Linux interaction and production-scale workloads remain pending. VEC-009 stays
partial because lasso, partial geometry and the full catalog acceptance remain open.
