# HM-04 compositor benchmark — macOS reference

Reproduce with `QT_QPA_PLATFORM=offscreen build/locked/opentoon_compositor_benchmark`
after a Release build. The fixture is generated by the benchmark source: a
1920 × 1080 scene with 19 overlapping drawing layers sharing a synthetic
256 × 256 RGBA image. Every third source pixel has zero alpha; the others
have partial alpha. No private or proprietary artwork is used. Each run warms
the renderer and times three frames per profile. Five process runs were made
on a MacBookPro18,3 (Apple M1 Pro, 16 GiB RAM), macOS 15.5, Qt 6.11.2.

| Profile | Median ms/frame | Range ms/frame |
|---|---:|---:|
| Direct legacy painter | 1.47 | 1.23–3.73 |
| Linear-sRGB graph after ink-region optimization | 28.98 | 28.60–29.37 |

The initial full-surface linear implementation measured 104 ms/frame on one
process run; a source-alpha scan reduced it to 76 ms/frame. Conservative ink
bounds then reduced the final five-run median to 28.98 ms/frame. The canvas
keeps at most 96 MiB of recently rendered preview frames; a 1080p premultiplied
frame occupies 8,294,400 bytes. Export remains uncached and uses an immutable
snapshot. A cache-hit lookup with an observed pixel read measured 0.079 µs
median in this microbenchmark; it excludes Qt Quick repaint/presentation cost.

These numbers are a development reference, not a production frame-time gate:
the fixture has no deformers, cameras, effects, dense full-frame paint or
large masks. Render output tests compare alpha coverage for rotated vectors
and sparse raster artwork; physical-tablet and other-platform performance
remain unqualified.

## Original character artwork, experimental.14

Run `QT_QPA_PLATFORM=offscreen build/locked/opentoon_compositor_benchmark --original-art`
after a Release build. The fixture uses the repository's original Clockwork Hello
scene specification and its 19 registered 256 × 256 sRGB PNG parts. A transparent
1920 × 1080 canvas and one character-root transform yield 20 layers. Five process
runs on the same development Mac, each with a warm-up and three measured frames:

| Profile | Median ms/frame | Range ms/frame |
|---|---:|---:|
| Direct legacy painter | 1.69 | 1.65–2.08 |
| Linear-sRGB graph | 37.45 | 36.22–38.83 |

The 1080p frame retains 8,294,400 bytes in the preview cache. The first cold
process run before the five-run series measured 46.77 ms/frame for linear output;
that startup variance is not included in the median. This fixture has real alpha
artwork but no deformation, effects, masks, camera or continuous motion. The
linear route is close to a 24 fps frame budget before presentation and editing
overhead, so it does not establish real-time playback for a full character shot.
